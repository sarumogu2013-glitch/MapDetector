# MapDetector

ローカルの地図タイル (z/x/y.png) をスムーズに表示し、クリックで座標を取得するデスクトップアプリ (Windows / Electron)。
図面 (DXF・画像・GeoJSON) と線形SIMAを重ねて表示でき、線形には指定した幅員の横断線を魚の骨のように描画します。

## 主な機能
- **タイルフォルダを開く**: `z/x/y.png|jpg|webp` 構造を自動検出します (1〜3階層下にあっても検出)。`tilemapresource.xml` があればTMS(Y反転)と判定し、手動でも切り替えられます。デスクトップ版は独自プロトコル `mdtile://` で直接配信し、ネイティブズーム外は拡大縮小で表示します。
- **座標取得**: 取得モード (P) でクリックすると、平面直角座標 X/Y (JGD2011 I〜XIX系) と緯度経度を記録します。CSV、SIMA (Shift_JIS)、クリップボードに出力できます。
- **スナップ**: 端点・中点・交点・円/円弧の中心・点・線上 (最近点)。図面、線形の中心線、幅員線、横断線、IP、主要点のすべてが対象です。Alt を押している間はスナップを無効にします。
- **図面オーバーレイ**: DXF (R12〜, Shift_JIS対応, ブロック/バルジ/円弧) は平面直角座標として配置します。XY入替と単位 (m/cm/mm) を指定できます。画像は3点ハンドルで位置合わせし、GeoJSON にも対応します。
- **線形SIMA**: IP、曲線半径R、クロソイドA1/A2から中心線を計算します。表示するもの:
  - 測点 (No.k+端数) と中間点
  - 主要点 (BC/EC/SP/KA/KE)
  - 左右幅員の横断線 (魚の骨)
  - 幅員線
  
  IP表は画面で編集できます。取得点からIPを作ることもできます。カーソル位置と取得点には、測点と中心線からの離れ (左+/右−) を表示します。横断線の座標はCSVで出力できます。
- **線形SIMA (TREND-ONE 等の形式)**: 要素レコード (`C01` 円曲線 / `C02` クロソイド) と、その所属IPを示す `C04` から IP と半径を組み立てます。`F03` の追加距離、`B03` から求めた測点間隔、`B04` の幅杭の幅を自動で設定し、測点は追加距離で表記します。ファイル内の中心線測点・幅杭座標と計算結果を照合し、最大差を表示します。
- **SIMA (JPGIS版) XML**: `jsima102.xsd` 準拠の XML を読みます。現場情報の座標系で系番号を自動で設定し、測点・基準点・水準点・画地・開放型画地を表示します。XML 版には路線要素がないため、線形は点名 BP/IP/EP から組み立てます (曲線半径はIP表で入力)。
- **プロジェクト保存**: 「名前を付けて保存 / 上書き保存 / 開く / 新規」に対応しています。画面の状態は1つのプロジェクトファイル (.mdp) にまとめて保存します。
  - 保存する内容: 表示位置、座標系、レイヤー、線形の設定・IP表、取得点、スナップ設定
  - 読み込んだ SIMA・図面: ファイル本体をプロジェクトに埋め込みます。
  - タイル: 重いため、フォルダの場所だけを記録します。
  - デスクトップ版の動作: 未保存のまま閉じると確認が出ます。次回起動時は前回のプロジェクトを開きます。
- **測点 (横断線の位置) の編集**: 線形欄の「測点を表で編集」で、測点名と追加距離を表で編集できます。
  - 座標 (中心・左端・右端の X/Y) は追加距離から自動で計算します。幅員は線形欄の左右幅員で一律です。
  - 追加距離を変えると、自動で付けた測点名も追従します。
  - 行を追加すると、任意の位置に横断線を入れられます。
  - 「自動生成に戻す」で、測点間隔による自動生成に戻ります。
- **表計算風の編集**: SIMA の座標点、IP表、取得点を、画面下部の表で編集できます。
  - 操作: セル選択、Excel とのコピー/貼り付け、行の挿入・削除 (右クリック)、元に戻す (Ctrl+Z)
  - 最下段の「*」行に入力または貼り付けると行が追加されます。
  - 編集した SIMA 座標点はプロジェクトに保存され、SIMA 形式で出力できます。
- **地図の回転**: メイン画面の地図を回転できます。
  - 操作: 右ドラッグ、Ctrl+ドラッグ、Shift+ホイール、左上の方位ボタンのドラッグ
  - ステータスバーで回転角を数値入力できます。「北↑」で北を上に戻します。
- **範囲を指定して印刷** (ファイル → 印刷、Ctrl+P): 次の順に設定して印刷します。
  1. 用紙 (A4〜A0、縦横、解像度、余白)
  2. 地図上の用紙枠をドラッグして範囲を配置
  3. 表示レイヤーを選択
  4. 縮尺を選択: 「地図の縮尺 (ズームに合わせる・既定はタイルの最大)」か、1:250 / 1:500 / 1:1,000 / 1:2,500 / 1:5,000 / 1:10,000 / 任意。固定縮尺では、用紙枠の大きさがその縮尺で決まります。
  5. 回転を「表示角のまま」か「北上」から選択
  6. 方位図・縮尺バーは自動で配置され、下欄にタイトル・座標系・縮尺・日付が入ります。

  PDF にしたいときは、印刷ダイアログで「Microsoft Print to PDF」を選びます。
- **背景地図**: 地理院タイル (淡色/標準/写真) を任意で表示できます。

## 開発
```bash
npm install
```
```bash
npm start
```
```bash
npm test
```
ブラウザ版として `index.html` を Chrome/Edge で直接開いても動きます (File System Access API を使用。Shift_JIS での保存はデスクトップ版のみ)。

テスト用のダミータイルは次で生成できます。
```bash
python3 scripts/make-sample-tiles.py /path/to/tiles
```
サンプルは `samples/` にあります。

## バージョンと自動更新
- バージョンは `package.json` の `version` (0.0.0 形式) だけで管理します。`npm run sync-version` で `js/version.js` を生成し、`npm start` と `npm run build` の前には自動で実行されます。
- リリース手順: 次を実行してコミット・push するだけです。未リリースのバージョンが push されると `.github/workflows/release.yml` がタグ `v<version>` を作り、 Windows インストーラを作って GitHub Releases に公開し、インストール済みのアプリは起動時と6時間ごとに更新を確認して自動更新します。
  ```bash
  npm version patch --no-git-tag-version
  ```
- 自動更新 (electron-updater) はトークンなしで GitHub Releases を読むため、**リポジトリは public である必要があります**。
- ビルドは今は `windows-latest` で行います。セルフホストランナー (SARU_MOGU3) をこのリポジトリに登録すれば、`runs-on: [self-hosted, Windows, X64]` に切り替えられます。

## 構成
| ファイル | 内容 |
|---|---|
| `electron/main.js`, `preload.js` | ウィンドウ、メニュー、`mdtile://`、ファイルIO、自動更新 |
| `js/menu-def.js` | メニュー定義 (ネイティブメニューとブラウザ版HTMLメニューで共通) |
| `js/app.js` | 画面ロジック |
| `js/tiles.js` | ローカルタイル |
| `js/imageoverlay.js` | 画像位置合わせ |
| `js/jprcs.js` | 平面直角座標変換 (pyproj と比べて誤差 < 1mm) |
| `js/alignment.js` | 線形計算 |
| `js/sima.js`, `js/simaxml.js`, `js/dxf.js` | SIMA (CSV / JPGIS XML) / DXF 読み書き |
| `js/snap.js` | スナップ (空間インデックス) |
| `js/grid.js` | 表計算風グリッド |
| `docs/CONTRACTS.md` | モジュール間の仕様 |

SIMA の路線レコード (F00〜F99, C00〜C99) はメーカーによって項目が違うため、寛容に解釈しています。読み込み結果が違う場合は、実際のファイルを共有してもらえれば合わせます。
